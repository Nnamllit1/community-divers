# Community Divers identity

The primary emblem shows three armored divers, gold wings and a curved teal
Super Earth. The standalone logo contains no title or tagline.

## Assets

- `logo.svg`: primary editable vector emblem, with 21 paths in four flat colors.
- `logo.png`: transparent raster export of the primary SVG.
- `mark.svg`: alias of the primary vector emblem.
- `mark-mono.svg`: light single-color emblem for dark surfaces.
- `mark-dark.svg`: dark single-color emblem for light surfaces.
- `icon.png`: transparent 512-pixel application icon.
- `launcher.ico`: Windows icon with 32, 48, 64, 128 and 256-pixel images.
- `wordmark.svg`: optional stacked title and tagline lockup.
- `horizontal.svg`: optional horizontal title lockup.
- `logo-generated.png`: source artwork for the primary vector trace.
- `logo-generated.svg` and `logo-generated-flat.png`: trace and matching export.

The SVG artwork uses editable vector paths and contains no embedded bitmap or
font dependency. Single-color variants use a native SVG mask to preserve the
openings in the armor and visors. Keep breathing room around the wings and use
the single-color marks where color contrast is limited.

| Color | Hex | Use |
| --- | --- | --- |
| Signal gold | `#F4CF63` | Wings and armor accents |
| Community teal | `#72E3CB` | Shared world |
| Chalk | `#F1F3EE` | Armor |
| Deep navy | `#10191F` | Visors, gaps and dark surfaces |

Community Divers is an independent fan project. Its identity does not indicate
affiliation with or endorsement by the game's developers or publisher.
